# 对象脚本的用户代码视图

编辑器输入、标准粘贴及“转换缩进为空格”统一使用四列制表位：行首 Tab 转为四个空格，混合空格时补齐到下一个四列边界。只转换代码行首 Tab，字符串内容及已有纯空格缩进保持。菜单转换可撤销，词法状态复用 `PythonWrapperIndentation`，区域边界来自模型与动态锚点，不重新猜测标题。加载与保存不主动规范化旧文本。

v2/v3 多区域模型、模板生成、识别、保存合并和隐藏包装缩进的编辑视图已实现。v2 规则见 [区域协议](../../../../tools/python-helper/object-script-v2.md)，v3 新增 [受管理导入协议](../../../../tools/python-helper/object-script-v3.md)。新建角色/背景使用 v3；v1/v2 保持兼容，通过预览确认升级，不自动迁移。`ObjectScriptRegion` 记录稳定身份、类型、范围、包装缩进及事件身份；`ObjectScriptRegionSaveService` 生成计划，由既有保存服务应用。

`ScriptImportService` 编排只读分析和候选导入源码，`ManagedImportsBlock` 记录稳定项目身份及语句信息。普通用户脚本由 `UserScriptImportProjection` 隐藏模块级受管理区并保护摘要；对象投影在用户区域之前显示摘要。两者共用 `ISourceProjection` 行列转换，保留原始完整源码用于引用、保存和重命名。界面浮层及输入保护属于 App；AST、标准库发现及规则诊断属于 Helper，不执行用户代码。

角色和背景脚本的用户区域用于对象成员与事件逻辑，例如成员属性、实例方法及事件处理方法。模块级变量、普通函数和独立类应放在普通用户脚本中；这一约定不限制普通用户脚本。当前不新增 AST 层面的成员类型限制，不将错误缩进导致的作用域变化解释成用户区域丢失；专门的语义诊断属于后续功能。

`MultiRegionProjection` 为 v2 生成只读标题与用户切片，标题不参与解析区域身份。`PythonWrapperIndentation` 在字符串之外隐藏一层或两层包装缩进，保留用户自身嵌套结构；字符串延续行不增删空格，未修改行复用原始文本。`MultiRegionReadOnlyProvider` 通过动态锚点保护标题及分隔符，区域内使用原生编辑和撤销重做；跨只读边界的删除整体拒绝，选择和复制正常。

完整源码用于保存和分析。v2 根据可信区域模型生成保存计划，不在每次输入或保存时重新猜测边界；保存后更新基线，继续检查版本、清单和磁盘冲突。用户删除 pass 后可保存空方法体，语法诊断正常报告；不隐藏或补回占位语句。“更多 → 添加”已接入方法插入和占位整行自动选中，以及通过 `ObjectScriptFeatures` 添加初始化区域。初始化使用显式可信结构命令，保存时仍复检原始磁盘基线。

App 层 `StructuralEditorHistory` 将原生文本操作和前后 `StructuralEditorState` 组成同一个原生撤销组。边界操作仅恢复可信文档模型、投影、动态锚点及有方向的选区；播放期间只由原生文本撤销操作修改文档，不重新解析源码或替换整个 TextEditor.Text 清空历史。结构保存基线独立于历史快照，因此保存后撤销仍可以移除初始化包装，同时使用最新磁盘源码做冲突检查。重新加载、切换文档时清空历史；普通保存保留历史。其他结构命令未来复用此机制。

`IEditorProjection` 统一诊断、引用查询及跳转的行列转换；v2 同时转换行号与包装缩进引起的列号变化。用户输入同名中文标题是普通代码注释，不改变模型身份。

`ObjectScriptDiagnostics` 在既有映射之后处理诊断归属和去重。只对已确认包装过滤隐藏位置的恢复诊断；原生与未知来源错误不能据此丢弃。缺少代码块时根据原生错误中的定义行或恢复解析提供的 `relatedLine` 定位用户定义；系统事件方法的空用户体定位到该区域。独立用户区域错误继续显示，未知位置使用中性提示。界面计数、表头和状态栏提示统一使用展示结果，点击仍复用已有的 `DiagnosticSelection`。结构损坏的完整源码恢复视图不参与隐藏过滤。

初始化在用户视图中固定放在类定义与启动代码之间，视图顺序独立于磁盘区域顺序；无修改时完整源码仍逐字保持，范围、映射和动态锚点按稳定 ID 对应。添加方法使用主窗口内遮罩浮层；方法和初始化占位均选择包含缩进和提示注释的整行，不包含换行。

## v1 兼容视图

资源筛选器通过 `ObjectScriptTemplateVersion` 读取头部版本提示，仅旧版角色/背景显示 `WarningOutlined`；此提示不代替结构校验。`ObjectScriptUpgradeService` 在用户明确选择升级时重新验证 v1，完整保留用户区域原文到 v2 members，并生成默认 start，重新验证候选结构；服务不写磁盘。界面展示用户视图预览，确认后使用同一结构撤销栈应用，支持跨 v1/v2 恢复投影、选区和只读边界；保存仍检查最新磁盘基线。最新模板升级入口置灰；无标记、损坏、普通用户脚本和未来版本不参与此迁移。

`ObjectScriptProjection` 将已确认的单用户区域原文作为视图，继续保留原始缩进。系统导入、类包装及标记不显示，v1 不被自动重写为 v2。

视图按 UTF-16 偏移和原始行列映射；由于没有去除缩进，列号不变。诊断列表使用视图行号，引用查询将光标映射至完整源码，引用跳转在目标视图准备好后执行。隐藏系统代码中的结果只提示来源，不跳到用户代码中的无关位置。

非空视图未以换行结束时，合并层补充与原文件一致的 LF/CRLF，保证隐藏结束标记独占一行；该分隔换行写入用户区域，重新加载后作为区域原文显示。空视图不补充换行。其余内容不自动格式化，保存仍复用系统包装和磁盘冲突复检。

普通用户脚本及旧版未标记对象脚本全文显示；区域识别失败时显示只读完整源码作为恢复入口，不猜测边界或迁移模板。
